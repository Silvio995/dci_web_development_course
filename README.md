# DCI Web Development Course

This repository documents my learning path during the Full Stack Web Development course at DCI - Digital Career Institute.

It serves as a public portfolio and index repository. Homework and exam projects are maintained as separate GitHub repositories because assignments are cloned, completed, submitted, and pushed independently. This repository provides an organized overview with links to each assignment.

Each course module is organized into:

- `homework/` for links to completed assignments
- `theory/` for personal notes and theory documents

## Technologies Studied

- HTML
- CSS
- JavaScript
- TypeScript
- Node.js
- PostgreSQL
- SQL
- Sequelize ORM
- React
- Next.js
- Git
- GitHub
