## Cos'è la Programmazione Orientata agli Oggetti?

Fino ad ora abbiamo lavorato soprattutto con un approccio chiamato **programmazione procedurale**.

Nella programmazione procedurale il codice è spesso composto da tante funzioni separate.

Esempio:

```js
function createUser(email, password) {
  return {
    email,
    password,
  };
}

function loginUser(user, password) {
  return user.password === password;
}

function changePassword(user, newPassword) {
  user.password = newPassword;
}
```

Questo approccio funziona, ma quando un progetto cresce può diventare difficile da gestire, perché abbiamo:

- tante funzioni sparse
- dati separati dalle funzioni
- codice meno organizzato
- più rischio di confusione

La **Programmazione Orientata agli Oggetti**, invece, cerca di organizzare il codice in modo più ordinato.

Con la OOP raggruppiamo insieme:

- i dati
- le funzioni che lavorano su quei dati

Questo gruppo viene rappresentato da un **oggetto**.

---

## Idea principale della OOP

La OOP permette di dividere il codice in **classi**.

Una classe rappresenta un concetto indipendente del programma.

Può rappresentare qualcosa di reale, per esempio:

- `User`
- `Product`
- `Pet`
- `Order`
- `Book`

Oppure può rappresentare una parte funzionale del programma, per esempio:

- `Logger`
- `Config`
- `Database`
- `EmailService`

L'idea è questa:

> Una classe tiene insieme dati e comportamenti collegati tra loro.

---

## Classe e oggetto

Una **classe** è come un progetto, un modello o un bauplan.

Un **oggetto** è una cosa reale creata partendo da quella classe.

Esempio semplice:

```js
class User {
  constructor(email, password) {
    this.email = email;
    this.password = password;
  }

  login(password) {
    return this.password === password;
  }
}

const admin = new User("admin@example.org", "Passw0rd!");
```

In questo esempio:

- `User` è la classe
- `admin` è un oggetto creato dalla classe
- `admin` è anche chiamato **istanza** della classe `User`
- `email` e `password` sono proprietà
- `login()` è un metodo

---

## Cosa significa istanza?

Quando creiamo un oggetto usando `new`, stiamo creando una **istanza** della classe.

```js
const user1 = new User("user1@example.com", "1234");
const user2 = new User("user2@example.com", "abcd");
```

Qui abbiamo:

- una sola classe: `User`
- due oggetti diversi: `user1` e `user2`
- ogni oggetto ha i propri dati

---

## Proprietà e metodi

In una classe possiamo avere:

### Proprietà

Le proprietà sono i dati dell'oggetto.

Esempio:

```js
this.email = email;
this.password = password;
```

### Metodi

I metodi sono funzioni dentro una classe.

Esempio:

```js
login(password) {
  return this.password === password;
}
```

Un metodo descrive cosa può fare un oggetto.

---

## Esempio semplice: classe Pet

```js
class Pet {
  constructor(name, type) {
    this.name = name;
    this.type = type;
  }

  introduce() {
    return `Ciao, sono ${this.name} e sono un ${this.type}.`;
  }
}

const dog = new Pet("Luna", "cane");
const cat = new Pet("Milo", "gatto");

console.log(dog.introduce());
console.log(cat.introduce());
```

Output:

```txt
Ciao, sono Luna e sono un cane.
Ciao, sono Milo e sono un gatto.
```

Qui `Pet` è una classe generale.

Poi creiamo due oggetti diversi:

- `dog`
- `cat`

Entrambi hanno le stesse proprietà e gli stessi metodi, ma dati diversi.

## Il costruttore: constructor

Il metodo `constructor` viene eseguito automaticamente quando creiamo un nuovo oggetto con `new`.

Esempio:

```js
class Product {
  constructor(name, price) {
    this.name = name;
    this.price = price;
  }
}

const product = new Product("Laptop", 999);
```

Quando scriviamo:

```js
new Product("Laptop", 999)
```

JavaScript chiama automaticamente il `constructor`.

Quindi:

```js
this.name = "Laptop";
this.price = 999;
```

---

## Il significato di `this`

Dentro una classe, `this` indica l'oggetto corrente.

Esempio:

```js
class User {
  constructor(email) {
    this.email = email;
  }

  showEmail() {
    return this.email;
  }
}
```

Se creiamo:

```js
const user = new User("test@example.com");
```

Allora dentro quell'oggetto:

```js
this.email
```

significa:

```js
user.email
```

Quindi `this` serve per accedere alle proprietà e ai metodi dell'oggetto corrente.

---

## Le classi sono come modelli

Possiamo immaginare una classe come uno stampo.

La classe non è l'oggetto reale, ma serve per creare oggetti reali.

Esempio:

```js
class Car {
  constructor(brand, model) {
    this.brand = brand;
    this.model = model;
  }

  drive() {
    return `${this.brand} ${this.model} sta guidando.`;
  }
}

const car1 = new Car("Fiat", "Panda");
const car2 = new Car("Dacia", "Sandero");

console.log(car1.drive());
console.log(car2.drive());
```

Output:

```txt
Fiat Panda sta guidando.
Dacia Sandero sta guidando.
```

## 1. Ereditarietà

L'ereditarietà permette a una classe di ereditare proprietà e metodi da un'altra classe.

In JavaScript si usa la parola chiave `extends`.

Esempio:

```js
class Animal {
  constructor(name) {
    this.name = name;
  }

  eat() {
    return `${this.name} sta mangiando.`;
  }
}

class Dog extends Animal {
  bark() {
    return `${this.name} abbaia.`;
  }
}

const dog = new Dog("Rex");

console.log(dog.eat());
console.log(dog.bark());
```

Output:

```txt
Rex sta mangiando.
Rex abbaia.
```

Qui:

- `Animal` è la classe padre
- `Dog` è la classe figlia
- `Dog` eredita il metodo `eat()` da `Animal`
- `Dog` aggiunge anche il proprio metodo `bark()`

---

## 2. Astrazione

L'astrazione significa mostrare solo le parti importanti e nascondere i dettagli non necessari.

Esempio pratico:

Quando usiamo un metodo come:

```js
user.login("password123");
```

non ci interessa sapere tutti i dettagli interni di come funziona il login.

Ci interessa solo usare il metodo.

Esempio:

```js
class User {
  constructor(email, password) {
    this.email = email;
    this.password = password;
  }

  login(password) {
    return this.password === password;
  }
}
```

Da fuori usiamo solo:

```js
user.login("password123");
```

Questo rende il codice più facile da usare e leggere.

---

## 3. Incapsulamento

L'incapsulamento significa proteggere i dati interni di una classe.

L'idea è che non tutto deve essere accessibile direttamente da fuori.

In JavaScript moderno possiamo usare `#` per creare proprietà private.

Esempio:

```js
class BankAccount {
  #balance;

  constructor(initialBalance) {
    this.#balance = initialBalance;
  }

  deposit(amount) {
    if (amount > 0) {
      this.#balance += amount;
    }
  }

  getBalance() {
    return this.#balance;
  }
}

const account = new BankAccount(100);

account.deposit(50);

console.log(account.getBalance());
```

Qui `#balance` è privato.

Questo significa che non possiamo fare:

```js
console.log(account.#balance);
```

Per leggere il saldo dobbiamo usare il metodo pubblico:

```js
account.getBalance();
```

---

## 4. Polimorfismo

Il polimorfismo significa che classi diverse possono avere metodi con lo stesso nome, ma comportamento diverso.

Esempio:

```js
class Animal {
  speak() {
    return "L'animale fa un verso.";
  }
}

class Dog extends Animal {
  speak() {
    return "Il cane abbaia.";
  }
}

class Cat extends Animal {
  speak() {
    return "Il gatto miagola.";
  }
}

const animals = [new Dog(), new Cat()];

for (const animal of animals) {
  console.log(animal.speak());
}
```

Output:

```txt
Il cane abbaia.
Il gatto miagola.
```

Il metodo ha sempre lo stesso nome:

```js
speak()
```

Ma ogni classe lo implementa in modo diverso.

# Esempio TypeScript: classe Todo

Con TypeScript possiamo aggiungere i tipi.

Esempio:

```ts
class Todo {
  title: string;
  completed: boolean;

  constructor(title: string) {
    this.title = title;
    this.completed = false;
  }

  complete(): void {
    this.completed = true;
  }

  print(): string {
    return `${this.title} - ${this.completed ? "completato" : "da fare"}`;
  }
}

const todo = new Todo("Studiare OOP");

todo.complete();

console.log(todo.print());
```

Qui TypeScript ci permette di dichiarare:

```ts
title: string;
completed: boolean;
```

In questo modo il codice è più sicuro e più chiaro.

# Esempio: Todo List con oggetti

Possiamo creare una lista di oggetti partendo da una classe.

```ts
class Todo {
  title: string;
  completed: boolean;

  constructor(title: string) {
    this.title = title;
    this.completed = false;
  }

  complete(): void {
    this.completed = true;
  }
}

const todos: Todo[] = [
  new Todo("Studiare classi"),
  new Todo("Fare esercizi"),
  new Todo("Ripassare TypeScript"),
];

todos[0].complete();

console.log(todos);
```

Qui:

- `Todo` è la classe
- ogni elemento dell'array è un oggetto `Todo`
- possiamo chiamare metodi su ogni oggetto

# Differenza tra programmazione procedurale e OOP

## Programmazione procedurale

Nella programmazione procedurale abbiamo funzioni separate.

```js
function createProduct(name, price) {
  return { name, price };
}

function applyDiscount(product, discount) {
  product.price = product.price - discount;
}
```

## Programmazione orientata agli oggetti

Nella OOP mettiamo dati e metodi nella stessa classe.

```js
class Product {
  constructor(name, price) {
    this.name = name;
    this.price = price;
  }

  applyDiscount(discount) {
    this.price = this.price - discount;
  }
}

const product = new Product("Laptop", 999);
product.applyDiscount(100);
```

La seconda versione è più organizzata perché il comportamento del prodotto sta dentro la classe `Product`.

# Mini-cheatsheet

## Classe

Una classe è un modello per creare oggetti.

```js
class User {
  // codice
}
```

## Oggetto / istanza

Un oggetto è creato da una classe.

```js
const user = new User();
```

## Constructor

Il `constructor` viene eseguito quando creiamo un nuovo oggetto.

```js
constructor(name) {
  this.name = name;
}
```

## Proprietà

Sono i dati dell'oggetto.

```js
this.name = name;
```

## Metodo

È una funzione dentro una classe.

```js
sayHello() {
  return "Ciao";
}
```

## `this`

Indica l'oggetto corrente.

```js
this.name
```

## `extends`

Serve per creare ereditarietà.

```js
class Dog extends Animal {}
```

## Proprietà privata

Si usa `#`.

```js
#password;
```

# Esercizio guidato

Crea una classe `Book`.

La classe deve avere:

- `title`
- `author`
- `pages`
- un metodo `describe()`

Esempio:

```js
class Book {
  constructor(title, author, pages) {
    this.title = title;
    this.author = author;
    this.pages = pages;
  }

  describe() {
    return `${this.title} è stato scritto da ${this.author} e ha ${this.pages} pagine.`;
  }
}

const book = new Book("Il piccolo principe", "Antoine de Saint-Exupéry", 96);

console.log(book.describe());
```

# Riassunto finale

La Programmazione Orientata agli Oggetti serve per organizzare meglio il codice.

Invece di avere tante funzioni sparse, creiamo classi che rappresentano concetti precisi del programma.

Una classe può rappresentare un elemento reale, come `User`, `Product`, `Pet`, oppure una parte tecnica del programma, come `Logger` o `Config`.

Le classi permettono di tenere insieme:

- dati
- metodi
- logica
- comportamenti

I concetti più importanti da ricordare sono:

- classe
- oggetto
- istanza
- proprietà
- metodo
- constructor
- this
- ereditarietà
- astrazione
- incapsulamento
- polimorfismo

Questa lezione è importante perché le classi sono molto usate in tanti linguaggi di programmazione, come Java, PHP, Python, Ruby e anche JavaScript/TypeScript.
